# CareerSenseAI 🚀

> AI-Powered Placement Preparation & Resume Intelligence Platform

CareerSenseAI is a Final Year Major Project that helps students prepare for placements using Artificial Intelligence, Machine Learning, and NLP.

The platform combines Resume Analysis, ATS Scoring, Job Description Matching, AI Interview Preparation, Skill Gap Analysis, and PDF-based AI Chat into a single application.

---

## 🎯 Project Vision

To build an intelligent platform that simplifies placement preparation for students by integrating multiple AI-powered tools into one system.

---

## 📌 Core Features

- Resume Analysis
- ATS Score Checker
- Job Description Matching
- AI Interview Question Generator
- Resume Chatbot
- Skill Gap Analyzer
- Learning Roadmap Generator
- PDF Chat (RAG)
- Placement Dashboard
